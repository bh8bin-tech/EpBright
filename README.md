# EpBright

根据环境光与个人亮度曲线，自动调节手机屏幕亮度。适用于 Android 12 及以上；主要面向 vivo 使用场景，其他品牌可尝试，兼容性以实际手机表现为准。

**当前版本：0.5.9 测试版 · 免费使用 · 源码不公开**

## 开始使用

1. 下载并安装 APK，允许当前浏览器或文件管理器安装应用。
2. 阅读软件内隐私说明，授予“修改系统设置”和“使用情况访问”权限。
3. 点击“开始自动调节”，按软件内后台指南设置保活；允许通知，方便查看状态与停止服务。
4. 默认使用全局曲线。需要时再为个别应用开启独立策略，无需逐个设置。

曲线默认锁定：控制中心的手动亮度仅在当前应用临时生效，退出应用或息屏后结束。想让软件记住调节，请解锁对应曲线并开启同步。停止服务会尝试恢复启动前的系统自动/手动亮度模式；若权限已被撤销，重新授权并回到首页后重试。

## 使用说明与反馈

无需 Root、Shizuku 或无障碍服务；没有账户、广告或自动上传。重启手机后需要手动启动。软件不能突破系统的 HDR、强光或温控限制。

问题反馈页可自愿记录和导出日志。日志包含设备信息、照度、亮度与前台应用包名，分享前请自行检查。提交问题时描述手机型号、系统版本和复现步骤即可，日志不是必填项。
